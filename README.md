**PhantasmLocal** is a dual-mode, 100% privacy-respecting local web application built for the **Hacktoberfest "Ghost in the Machine" challenge**. It combines the reverent warmth of **Día de los Muertos** (Nov 1–2) with the eerie nostalgia of **1990s retro horror & BBS dial-up terminals** (Oct 31).

Built entirely around open-source AI principles, **PhantasmLocal** operates with zero cloud telemetry or external API dependencies—keeping family stories, memorial photos, and system diagnostics entirely on your local machine.

---

## 🌟 Core Features

### 1. 🕯️ Día de los Muertos Digital Memory Ofrenda (Altar)
* **Warm Candlelit Aesthetic:** Candle-lit gradients, marigold flower accents, and flickering memorial typography.
* **Polaroid Memory Vault:** Pin family photos and stories with instant client-side rendering and grainy vintage filters.
* **Local AI Calavera Literaria Generator:** Synthesizes custom, witty, and heartwarming rhyming verses celebrating passed loved ones using local open-weight model architectures (**Gemma-2**).
* **Portable Memory Bundles:** Export your entire altar as a self-contained, offline-ready `.html` capsule that works for decades without internet.

### 2. 💻 199X Haunted Terminal & BBS Séance
* **Retro CRT Scanlines & Glitch Engine:** Authentic MS-DOS / terminal green-and-red phosphor aesthetics with spontaneous screen glitches and static bursts.
* **Possessed Shell Commands:** Run commands like `dir`, `whoami`, `scan` (powered by TabPFN process anomaly detection), and `exorcise`.
* **Extinct Language Séance Room:** Commune with the digital spirits of abandoned programming paradigms (**COBOL 85**, **Turbo Pascal 7.0**, **Macromedia Flash ActionScript 2.0**).
* **Shortwave Ghost Radio Prop:** Tune frequencies across the dial (88.0–108.0 MHz) to intercept creepy numbers station broadcasts and dial-up handshakes.

### 3. 🎵 Autonomous Horror Web Audio Engine
* **Zero External Audio Files:** 100% pure browser-synthesized **Web Audio API** soundscapes.
* **Ambient Horror Soundtrack:** Automatically kicks in on your first click, playing a slow subterranean creepy drone interspersed with sudden horror shouts, static bursts, and ghostly laughs.
* **Mechanical Typing Feedback:** Harsh metallic key-clicks accompany every keystroke in the terminal.
